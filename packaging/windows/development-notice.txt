Blue Ash Reel Development - unsigned per-user Windows Agent

This development build is unsigned. Windows may display an unknown-publisher
or SmartScreen notice. Keep Windows security protections enabled.

The Agent runs in your Windows system tray while you are signed in. It uses
your existing access to drives and authorized network shares. Fresh installs
do not require administrator rights, services, Docker or additional runtimes.
The inbox Windows .NET Framework runs the native tray; all media runtimes
are bundled. Supported: 64-bit Windows 10 22H2 and Windows 11.

Program files default to your LocalAppData Programs directory. Database,
artwork/cache, temporary transcodes, backups and logs use separate directories
under LocalAppData\BlueAshReel-Development. The Advanced pages allow separate
locations. Existing storage settings survive repair and upgrade.

Installation configures runtime settings only. After installation sign in at
https://blueashreel.com, complete email MFA, and confirm Agent pairing locally.
Create libraries in the authenticated Portal and approve folders using the
native picker on this workstation. Source media is read-only.

Loopback is the only local listener. Media-provider network integrations stay
disabled. The device connector connects outbound to the canonical Portal over
TLS and carries application-layer encrypted browser/Agent sessions.

Migration of a previous service installation needs Windows elevation only
for backup, stopping legacy services, and granting your Windows account access
to its retained data. A validated backup and old configuration/permissions
are preserved. Legacy service program files remain available for rollback; registrations are removed
only after the new tray Agent is healthy. Service-bound DPAPI identity material
is retained; fresh user-confirmed pairing is required when it cannot safely be
used by your Windows account. A failed health check triggers legacy rollback.

Uninstall stops this Agent and preserves all data, settings and backups.
Third-party notices and corresponding source are included in the package.
